# Neon Arena — Original Multiplayer FPS

## Requirements
- Windows/macOS/Linux
- Node.js 18+ recommended

## Run
Open a terminal in this folder:

```bash
npm install
npm start
```

Then open:

http://localhost:3000

## Test multiplayer
Open the address in two browser windows/tabs. Enter different names and press PLAY.

This is a starter prototype. The next upgrades can include proper server-side raycasting, collision, jumping, weapons, maps, teams, matchmaking, sound, animations, and mobile controls.
